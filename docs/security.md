# Security & Air-Gap Sovereignty

Industrial data processed by MRPL (refinery P&IDs, safety audits, financial spreadsheets) requires absolute data sovereignty.

---

## 1. Structural Air-Gapping Guarantees

1. **Docker Internal Network:** All inter-service communication (Frontend ↔ Backend ↔ Ollama ↔ Qdrant ↔ Postgres) runs on a bridge network configured with `internal: true`. Docker does not create NAT routing rules to the outside world.
2. **Host-Level Egress Drop:** An explicit `iptables`/`ufw` rule rejects outbound TCP/UDP packets from the workbench UID:
   ```bash
   sudo iptables -A OUTPUT -m owner --uid-owner 1000 -d 127.0.0.0/8 -j ACCEPT
   sudo iptables -A OUTPUT -m owner --uid-owner 1000 -j DROP
   ```
3. **No Dynamic Model Pulls:** All model weights (`.gguf` / Ollama blobs) are mounted from a local persistent volume (`ollama_models`).

---

## 2. Network Sentinel Daemon

The Sentinel service monitors active socket connections in real time by reading `/proc/net/tcp` and querying socket status:
- Counts all non-loopback active socket connections.
- Exposes metrics over `/api/network/status`.
- Powers the top-bar green status widget on the frontend (`✔ AIR-GAPPED`).

---

## 3. Sandboxed Code Execution

Dynamic Python scripts generated by the coding agent are isolated in a non-root, zero-network container with memory and execution time limits to prevent resource exhaustion or privilege escalation.
